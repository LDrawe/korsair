# 🏴‍☠️ Korsair – A modern icon Theme for KDE Plasma 6

**Korsair** is a modern icon theme, designed as a continuation of the *La Capitaine* icon theme for Plasma, with some little bits of *Kora*.

The goal of Korsair is to deliver a cleaner and beautiful experience for modern KDE desktops, with updated spacing, shapes and visual balance, fully adjusted for the design and scaling behavior of Plasma 6.

---

## ✨ Features

- Modernized visuals
- Carefully adjusted for KDE Plasma 6
- Dynamic CPU icon
  - Automatically switches depending on the detected vendor:
    - Intel
    - AMD
---

## 🧬 Project background

Korsair is a derivative and continuation project built on top of the visual foundations of:

- La Capitaine
- Kora

The project focuses on maintaining visual consistency while modernizing the original style to better fit the current and future KDE Plasma ecosystem.

## 🤝 Contributing

Contributions are very welcome.

You can help by:

- Redrawing or improving existing icons
- Fixing visual inconsistencies (padding, stroke, alignment and grid usage)
- Adding missing application and action icons
- Improving clarity and readability at small sizes

### Basic workflow

1. Fork the repository
2. Create a new branch for your changes
3. Keep the original grid, spacing and visual language
4. Test your icons on KDE Plasma
5. Open a pull request with a short description and screenshots

Please make sure that:

- New icons follow the existing style and proportions
- File names follow the FreeDesktop icon naming specification
